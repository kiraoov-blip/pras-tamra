# 탐라는 전기예보제 계산엔진 설계 초안

## 1. 분석 목적

동일한 시간별 사용량을 기준으로 현행 요금제와 전기예보 할인 적용안을 각각 계산하고, 두 결과의 차이를 고객·한전·계통 관점으로 분해합니다.

## 2. 계산 흐름

1. 입력자료 정합성 검사
2. 시간별 발령 여부 판정
3. 고객 참여량과 부하이전량 산정
4. 에너지 총량 보존 조건으로 시간별 부하 재배분
5. 현행·신규 요금 청구액 계산
6. 한전 판매수익 및 SMP 기반 구입비 계산
7. 고객·한전·계통 결과 집계

## 3. 주요 산식의 골격

### 참여 고객 수

`참여 고객 수 = 전체 대상 고객 수 × 참여율`

### 할인시간 단가

`신규 단가 = 현행 적용단가 × (1 - 할인율)`

주말할인과 전기예보 할인이 겹치는 경우에는 화면에서 선택한 우선순위에 따라 하나의 단가를 적용합니다. 중복할인 허용 여부는 별도 정책변수로 확장할 수 있습니다.

### 부하이전

`이전량 = 이전 대상 시간대 사용량 × 부하이전율`

이전 전후의 연간 전력사용량은 동일하게 유지합니다. 선택부하 시나리오는 가전·충전기별 이동 가능시간과 최대전력을 추가 제약조건으로 사용합니다.

### 고객 편익

`고객 편익 = 현행 연간 청구액 - 신규 연간 청구액`

전력량요금 외에 기본요금, 기후환경요금, 연료비조정요금, 부가가치세, 전력산업기반기금을 포함할지 입력자료별로 명시해야 합니다.

### 한전 단기 순재무영향

`단기 순재무영향 = 판매수익 변화 - 전력구입비 변화`

부호는 한전 관점으로 통일합니다. 판매수익 감소와 전력구입비 증가는 음수, 판매수익 증가와 전력구입비 감소는 양수로 표시합니다.

### SMP 기반 전력구입비 영향

`전력구입비 변화 = Σ[(신규 시간별 사용량 - 현행 시간별 사용량) × 시간별 제주 SMP]`

이 값은 SMP만 반영한 단기 에너지 구입비 영향이며, 용량요금·망 비용·손실률·정산조정계수 등은 포함하지 않는 별도 지표로 표시합니다.

## 4. 계산 모듈

| 모듈 | 입력 | 출력 |
|---|---|---|
| event | 시간별 SMP, 시간범위, 임계값 | 시간별 발령 마스크 |
| load | 기준 부하, 참여율, 이전율 | 현행·신규 시간별 부하 |
| tariff | 시간별 부하, 요금단가 | 고객 청구액, 판매수익 |
| purchase-cost | 시간별 부하차, SMP | SMP 기반 구입비 변화 |
| benefit | 각 모듈 결과 | 고객·한전·계통 편익 |

## 5. 우선 검증 항목

- 2025년 발령일 `56일`, 발령시간 `150시간` 재현
- 부하이전 전후 연간 사용량 오차 0 또는 허용범위 이내
- 고객유형별 엑셀 기준 결과와 웹 계산 결과 비교
- 할인율 0% 및 이전율 0%에서 기준안과 일치
- 참여율 100%에서 고객당 결과와 전체 결과의 배수관계 확인
- 음수 SMP 시간의 전력구입비 부호와 해석 검토
