# PRAS-TAMRA 계산 로직 점검 보고서

## 점검 범위

- 주택용 TOU 개별 계산파일 6개(이전율 0~100%)
- EV 완속·급속 개별 계산파일 6개
- 계절·주중/주말별 4인가구 가전부하 파일 6개
- 주택용·EV·일반용·산업용 판매수입 종합파일
- 할인 영향 분석 PDF와 기존 웹 엔진

## 발견사항과 조치

| 항목 | 발견사항 | 조치 |
|---|---|---|
| 계산 방식 | 기존 웹 엔진이 엑셀 기준점 사이를 선형보간해 중간 입력의 시간별 의미가 없음 | 모든 입력을 발령일·시간별로 재계산하는 엔진으로 교체 |
| 주택용 시나리오 1 | 종합 엑셀 총액을 화면 기본 고객 수 1,200으로 나눠 고객당 값으로 강제 보정 | 집계값 나눗셈 제거, 대표 고객 부하를 직접 이전 |
| 기본요금 | 중간 버전에서 원/kW 단가를 월 정액처럼 더해 계약전력을 반영하지 못함 | 기존 PRAS-EV 기준에 따라 기본요금을 분석대상에서 제외하고 전력량요금만 산정 |
| 주택용 주말단가 | 상세 주택용 파일에 EV용 토요일·공휴일 시간대 및 할인이 섞임 | 종합파일 `A.전기요금표`의 주택용 단가로 통일 |
| 발령시간 | 2025년 SMP≤0 집계는 150시간이나 실제 시나리오 구간은 195시간 | `실적 발령` 195시간과 `SMP 재판정` 150시간을 별도 모드로 분리 |
| 음수 SMP | 기존 문서는 음수 SMP가 없다고 했지만 원자료에 -1~-78.74원/kWh 존재 | 임계값 이하 조건에 음수 SMP를 포함 |
| 가전 이전 | 이전율을 선택가전 비중에 다시 곱해 모든 가전을 선택하지 않으면 실제 가전경로가 사라짐 | 선택한 가전의 시간별 부하를 각각 직접 이동 |
| 가전 음수부하 | 엑셀은 출발시간에 동일량을 차감해 저부하 시간에서 음수가 될 가능성 | 시간별 보유부하 한도 내에서 높은 요금시간부터 차감 |
| EV 2-1/2-2 | 기존 웹 엔진이 2-1을 급속 전용, 2-2를 완속 3시간 전용으로 구현해 사용자 정의와 불일치 | 두 시나리오 모두 완속·급속을 계산하도록 재구성. 2-1은 발령일 충전, 2-2는 주 2회 대표고객 충전으로 분리 |
| EV 고객구분 | 완속·급속 충전방식과 저압·고압 공급전압을 같은 개념으로 연결 | 계약전력 50kW 미만·이상에 따른 완속·급속 구분과 저압·고압 요금종별 선택을 분리 |
| EV 대표고객 | 완속·급속을 같은 평균부하곡선으로 처리해 7kW·50kW 정격과 월 사용량을 재현하지 못함 | 완속 7kW×6시간×월 8회=336kWh, 급속 50kW×1시간×월 8회=400kWh로 독립 구성 |

| 2026 기간 | 기존 엔진이 5/12 비율을 일괄 적용 | 5월 15일까지 135일 전력량요금 적용 |
| EV 공식 요금표 | 단가는 맞았으나 공식 요금표와 자동 대조하는 검사가 없어 변경 시 오류 가능 | 저압·고압 기본요금 단가와 계절·시간대별 전력량요금 18개를 상수화하고 회귀검사 추가 |

| 계절·요일 구분 | 원자료는 3개 계절·주중/주말 6개 부하곡선을 제공하지만 화면에서 연도 전체로만 합산 | 전체 선택을 기본값으로 유지하면서 계절·요일 필터를 발령일·부하·가전·요금·SMP 계산에 연결 |

## 정량 영향 예시

2025년 주택용 TOU, 할인율 50%, 실적 발령, 고객 1호 기준입니다.

| 이전율 | 시나리오 1 고객편익 | 시나리오 2 전체가전 고객편익 |
|---:|---:|---:|
| 0% | 10,142원 | 10,142원 |
| 50% | 19,669원 | 23,318원 |
| 100% | 29,196원 | 31,727원 |

이 값은 오류가 포함된 엑셀 총액에 맞춘 보정값이 아니라, 수정된 요금표와 시간별 이동경로를 적용한 엔진 결과입니다. 보고서 수치와 비교할 때는 대상 고객 수·수요이전율, 150시간 SMP 판정 또는 195시간 실적구간 중 어느 기준인지 함께 고정해야 합니다. 대상 고객 수에는 별도의 제도 참여율을 곱하지 않습니다.

## 남은 가정

- 기준자료 생성 시 원자료 요일표를 사용하되, 요금표상 임시공휴일 제외와 분석대상 법정공휴일을 명시적으로 보정합니다. 새로운 발령일을 추가할 때는 해당 연도의 공식 공휴일표도 함께 갱신해야 합니다.
- EV 연간 현행 전력량요금은 원자료의 검산 가능한 합계값을 사용하며, 향후 전체 연간 날짜별 충전실적이 제공되면 일별 재계산으로 교체할 수 있습니다.
- 전기차 전체의 완속·급속 고객수 비중은 원자료에 없어 2025년 사용량 비중(77.2%·22.8%)을 사용합니다. 대표고객 수 비중이 확보되면 고객수 가중으로 교체해야 합니다.
- 주 2회 충전은 월 4주·8회로 월 336kWh·400kWh를 맞추고, 충전요일이 평일·주말 안에서 균등하다고 가정합니다.
- 13개 가전의 보유율은 별도 조사값이 없어 체크 여부를 보유 여부로 간주합니다.
- 부가가치세, 전력산업기반기금과 기후환경·연료비 조정요금은 원 보고서와 동일하게 제외합니다.
